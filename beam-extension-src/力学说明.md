# 单筋矩形、双筋矩形与 T 形梁：计算模块说明

本模块用于正截面抗弯教学。曲线上的各点表示不同配筋方案按教材简化模型得到的抗弯能力，不是同一根梁的加载历程、荷载-位移曲线或有限元破坏模拟。输入弯矩 `M` 是用于截面验算的弯矩计算值，不在本模块内部重新进行荷载组合或乘结构重要性系数。

## 1. 教材依据与范围

依据《结构设计原理（第5版）》第 65—103 页节选（本仓库不包含教材 PDF）：

- PDF 第 24–26 页，印刷第 74–76 页：受压钢筋应变、式（3-24）至（3-30）、双筋设计的界限压区分解。
- PDF 第 30–32 页，印刷第 80–82 页：两类 T 形截面、式（3-31）至（3-37）、按腹板宽度进行最小配筋检查。
- PDF 第 27 页，印刷第 77 页：例 3-5，用作独立计算核对。

上述相关公式页已完整查看。模块沿用教材的等效矩形压应力图和同强度普通钢筋，忽略受拉混凝土对正截面抗弯的贡献。双筋计算还要求受压钢筋具备屈服条件。网页只展示计算关系；钢筋能否排入截面、选筋后的重心变化、封闭箍筋、剪力、锚固、裂缝、挠度和耐久等均需另行处理。

教材用 `x ≤ ξ_b h0` 表示边界；本模块允许计算等号，并显式给出 `teachingBoundary`。这不是“等号处已完成全部工程设计”的结论。

## 2. 参数与单位

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `fc` | 13.8 MPa | 混凝土抗压强度设计值 |
| `fy` | 330 MPa | 拉、压钢筋采用相同强度设计值 |
| `ft` | 1.39 MPa | 最小配筋计算使用的混凝土抗拉设计值 |
| `Es` | 200000 MPa | 钢筋弹性模量 |
| `b, h` | 250, 500 mm | 矩形宽/腹板宽、截面高 |
| `as, h0` | 40, 460 mm | 下筋重心距底、有效高度 |
| `xiB` | 0.53 | 界限相对受压区高度 |
| `bf, hf` | 650, 100 mm | T 梁受压翼板的有效宽度、厚度 |
| `ap` | 40 mm | 受压钢筋重心距顶；网页建议 40–100 mm |
| `beta, epsilonCu` | 0.8, 0.0033 | 教材辅助应变示意参数 |

计算内部使用 N、mm、MPa；所有对外弯矩字段使用 kN·m。`C/Cc/Cs/T` 是 N，长度是 mm，面积是 mm²。`rho` 和 `rhoMin` 是小数比例；0.002 表示 0.2%。`bf` 是计算有效宽度，不自动把真实桥面全宽视为有效宽度。

最小配筋：

\[
\rho_{\min}=\max(0.002,0.45 f_t/f_y),\qquad A_{s,\min}=\rho_{\min} b h_0.
\]

本例 `Amin = 230 mm²`。T 梁也按腹板宽 `b` 计算。教学曲线与单筋滑块从 `Amin` 开始。对低于最小值的直接正算，模块虽返回代数值，但同时返回 `valid=false`、`belowMinimum=true`，不能把它作为少筋梁的实际承载力。

## 3. 共同主公式与单筋矩形梁

页面对矩形、T形和其他变宽截面统一展示下列三个设计式，不随模式替换成不同外观的展开式：

\[
f_{cd}A_c=f_{sd}A_s,\qquad
M=f_{cd}A_cz,\qquad
M=f_{sd}A_sz.
\]

后两式是同一个弯矩的两种算法，不是需要相加的两部分。`Ac` 为等效受压混凝土面积；`z=ys−yc` 是混凝土压力重心与受拉钢筋重心的距离，两个深度均从顶面量起。`ys=Σ(As,i yi)/ΣAs,i=h0`，排筋变化时应重新计算。截面形状只改变 `Ac(x)` 和 `yc(x)` 的几何计算；采用均布等效压应力时，混凝土压力重心与该压区的面积重心重合。

主公式区中的 `fcd`、`fsd` 分别对应内部参数 `fc`、`fy`。超筋状态下，主区显示的是设计实线的界限计算：`x=xb`、`As=As,b`，并取界限对应的 `Ac` 与 `z`，不把 `fsd` 与当前超筋总面积相乘。双筋模式下，这三个式子仅用于原单筋基础部分，`As` 对应页面的 `As,1`，即 `AsBase=As,b`；下部总面积为 `As,总=As,1+ΔA`。具体几何展开与超筋虚线的材料应力关系放在折叠说明中；这次统一教学表达不改变设计模块和应变协调模块的计算。

底层计算中，适筋设计与超筋趋势仍沿用同一套力与力矩平衡；对于超筋虚线，以当前钢筋应力写为：

\[
\sigma_s A_s=C_c=f_cbx,\quad z=h_0-x/2,\quad M=C_cz.
\]

适筋时钢筋屈服，取 `σs=fy`，得到教材常用写法：

\[
x=\frac{f_yA_s}{f_cb},\quad C_c=f_cbx=f_yA_s,
\quad y_C=x/2,\quad M=C_c(h_0-y_C).
\]

界限取 `xb = xiB × h0 = 243.8 mm`，因此：

\[
A_{s,b}=2548.81818\ \mathrm{mm^2},\qquad M_b=284.379291\ \mathrm{kN\cdot m}.
\]

`mechanics.rect(As)` 在 `As > As,b` 时，返回停在界限的 **设计参考**，并标记 `over=true`、`valid=false`。`As` 保留输入值，`AsActive` 是该参考所计入的面积。设计实线在适筋段上升，到适筋界限后采用 `x=xb` 的上限值并水平延长；页面的设计抗力读数与目标复核按这条实线取值。水平实线不表示物理承载力停止增长，也不表示超筋成为推荐设计。三维压区、其 x 读数和棕色虚线则由 `section-response.js` 独立计算，见下一段。调用时不能把两种模型的x、钢筋应力和面积混用。

新增 `RCSectionResponse.solve(As,params,compressionAtX)` 按 εs=εcu(h0−c)/c、σs=min(fy,Esεs)、x=βc 和 σsAs=Cc(x) 求解完整配筋的应变协调状态。压区、压力重心和抗弯值可越过教材设计线继续增长；设计反算仍使用原界限。默认矩形As=3000时x=254.84053 mm、σs=293.06661 MPa、M=292.40405 kN·m；As=3300时x=260.50431 mm、M=296.35754 kN·m。以设计强度参数建立的简化趋势不等于试验真实破坏承载力，也不放宽适筋设计条件。

教材ξb=.53对应xb=243.8 mm；本构参数给出的屈服转折为β/[1+fy/(Esεcu)]=.533333，对应x=245.3333 mm。两条边界略有差异，代码如实分别保存。刚超教材线时不能一律说钢筋未屈服，应读取steelYielded。新模块14项测试验证连续性、力平衡、单调性、矩形独立解析根、T形及变宽积分、零值和输入边界。

## 4. 双筋矩形梁

此模式采用教材的一个明确分解：固定 `x = xb`，保留单筋界限所需的基础下筋 `AsBase`；上部新增 `AsTop`，下部新增 `AsExtra`。同强度且均可采用相同设计应力时：

\[
A_{s,\mathrm{extra}}=A_s',\qquad
A_{s,\mathrm{total}}=A_{s,b}+A_{s,\mathrm{extra}},
\]

\[
M_b=f_{cd}A_{c,b}z_b=f_{sd}A_{s,b}z_b,
\qquad z_b=h_0-y_{C,b},
\]

\[
\Delta A=A_{s,\mathrm{extra}}=A_s',\qquad
z_s=h_0-a_s',\qquad
\Delta M=f_{sd}\Delta A z_s,\qquad
M=M_b+\Delta M.
\]

页面分别给出基础部分 `Mb`、新增钢筋对 `ΔM` 及总抗力 `M` 的数值。主区共用三式解释基础部分；右侧推导只加上钢筋对这一项。`ΔA` 始终是新增**每侧**面积，不能替换成下部总面积。例3-5网页初始参数 `b=300, h=450, h0=385, ap=40 mm`、目标 `M=300 kN·m` 对应 `Mb=239.04794 kN·m`、`ΔM=60.95206 kN·m`、`zs=345 mm`，新增每侧 `ΔA=535.37161 mm²`。基础下筋 `As,b=2559.9 mm²`，下部总计 `3095.27161 mm²`。

相等的是上下 **新增**面积，上下总配筋面积不相等。力偶分解仍是同一截面的内力平衡，不是两套彼此独立、不需应变协调的实体结构。

模块检查 `xb >= 2 ap`，并辅助检查 `epsilonCu × (1 - beta × ap / xb) >= fy/Es`。本例允许的教材高度条件为 `ap ≤ 121.9 mm`，网页的 40–100 mm 均满足。若有新增受压筋而条件不满足，返回 `valid=false`、`M=null`，不偷换成仍然屈服的钢筋力偶；教材的其他计算分支不在本模块实现。

图中 `yC` 始终是 **混凝土**合力位置 `x/2`。混凝土箭头应使用 `Cc`，受压钢筋箭头使用 `Cs`；总压力 `C=Cc+Cs` 的位置另存为 `yCtotal`。受拉总力为 `T`。基础混凝土力臂 `leverArm` 与钢筋对力臂 `steelLeverArm=h0-ap` 不得混用。

若使用计算模块的默认截面参数、另取400 kN·m目标，`ap=40 mm` 时新增每侧 `834.20425 mm²`，下部总面积 `3383.02243 mm²`；这组参数与网页例3-5的初始参数不同。当新增每侧面积固定为 1000 mm²，把受压筋从 `ap=40` 下移到 100 mm，钢筋对力臂缩短60 mm，承载力减少19.8 kN·m。

## 5. T 梁与曲线光滑性

本节展开的是主公式中的受压面积和重心，主区仍统一显示 `fcd Ac=fsd As`、`M=fcd Ac z`、`M=fsd As z`。不把截面几何分支呈现为新的抗弯平衡原理。

令 `t = min(x, hf)`，可以统一计算两个分支：

\[
A_c=bx+(b_f-b)t,\quad
Q_c=\frac{bx^2+(b_f-b)t^2}{2},\quad
C_c=f_c A_c,\quad y_C=Q_c/A_c,
\]

\[
M=f_c(A_c h_0-Q_c),\qquad A_s=C_c/f_y.
\]

第一类 `x ≤ hf`，第二类 `x > hf`。这里比较的是等效压块高度 `x` 与翼板厚度；不是用真实中性轴深度 `cn` 分类。`cn=x/beta` 只是按教材参数形成的辅助应变示意。

默认参数的翼板边界为 `As=2718.18182 mm²`、`M=367.77 kN·m`；T 梁单筋设计边界为 `As=4221.54545 mm²`、`M=510.699291 kN·m`。在 400 kN·m 下，第二类 T 梁需要 `As=3000.03165 mm²`，`x=126.95955 mm`，`yC=55.96386 mm`。

当钢筋面积增长时：

\[
\frac{dM}{dA_s}=f_y(h_0-x),\qquad
\frac{d^2M}{dA_s^2}=-\frac{f_y^2}{f_cB(x)}.
\]

以上导数若 M 使用 kN·m，还需乘 `10^-6`。翼板内 `B(x)=bf`，进入腹板后 `B(x)=b`。在 `x=hf` 两边的 x 相同，所以 **M 与一阶斜率连续**，不能画生硬折角；改变的是二阶曲率。默认进入腹板后，负曲率绝对值增加到原来的 `bf/b=2.6` 倍。`slope` 是曲线切线斜率，不等于用当前内力臂 `h0-yC` 直接乘 fy 得到的割线关系。

## 6. API

普通浏览器 `<script>` 加载后使用 `window.RCMechanics`；Node 使用 `require('./mechanics.js')`。无需构建，也不访问 DOM。

```js
const r = RCMechanics.rect(1800);
const t = RCMechanics.tee(3000);
const d = RCMechanics.doubly(800, 40); // 下部新增800、上部新增800 mm²
const tDesign = RCMechanics.designT(400); // M以kN·m输入
const dDesign = RCMechanics.designDouble(400, 40);
const custom = RCMechanics.create({ h: 600, as: 45, bf: 700 });
```

`create(overrides)` 创建独立、不可变参数实例；`h0` 默认由 `h-as` 推导。若显式给出 `h0`，会反推 `as`；若两者同时给出且不满足 `h0=h-as`，抛出异常。负数、NaN、无穷值或不合理基础几何同样不接受。材料、`xiB`、`beta`、`Es` 等改变时，调用者必须同时给出互相配套的教学参数。

接口：`defaults`、`limits`、`rect(As)`、`tee(As)`、`doubly(extraAs, ap)`、`designRect(M)`、`designT(M)`、`designDouble(M, ap)`、`create(overrides)`。

主要返回字段：

| 字段 | 含义 |
|---|---|
| `mode` | `rect`、`double`、`tee` |
| `regime` | `rectangle`、`doubly`、`flange`、`web` |
| `x, yC, cn` | 等效压区高度、混凝土合力距顶、中性轴辅助示意深度 |
| `As, AsActive, AsIgnored` | 输入/总下筋面积、参考模型计入面积、超筋部分在设计参考中未计入的面积 |
| `AsBase, AsExtra, AsTop` | 基础下筋、新增下筋、上部计算受压筋 |
| `Cc, Cs, C, T` | 混凝土压力、钢筋压力、总压力、总拉力，N |
| `M, Mconcrete, Msteel` | 总弯矩、混凝土基础部分、钢筋对部分，kN·m |
| `over, atLimit, belowMinimum` | 超出单筋界限、正好处于界限、低于最小配筋 |
| `valid` | 当前简化公式及配筋上下限可用，不表示全部工程验算通过 |
| `teachingBoundary` | 正在展示界限分解或界限参考 |
| `ok, reason` | 反算是否可得方案及具体原因 |
| `AsNeeded` | 反算采用的总下筋面积；无法满足时为 null |
| `extraAsNeeded, AsTopNeeded` | 双筋反算新增每侧面积 |

单筋反算超过自身设计上限时返回 `ok=false`、`AsNeeded=null`，不无限加筋。低目标弯矩导致计算配筋低于最小时，采用 `Amin` 并说明承载力高于目标。双筋固定压区模式下，若目标原本可由单筋承担，`reason='single-sufficient'`、新增筋为0，并以 `recommendedSingle` 返回更直接的单筋解。

双筋模式没有根据排筋、构造等设置一个虚假的“无限可用”保证。数值上增大新增钢筋只用于教材的钢筋力偶敏感性讨论；极大的面积会受到实际布置、重心与其他极限状态限制。

## 7. 验证与教材中间数值

运行：

```text
node verify-mechanics.cjs
```

23项检查涵盖固定参考数值、压区独立分条积分、力与矩平衡、T 梁一阶连续与曲率变化、正反算往返、双筋上筋位置敏感性、超筋及最小配筋、教材例3-5、退化矩形、浏览器与Node加载、参数不变性。

本次独立积分检验的最大力平衡残差为 `1.12×10^-8 N`，最大弯矩残差为 `6.83×10^-13 kN·m`。

教材例3-3是跨度2.05 m、1 m宽计算带、100 mm厚的 C25/HPB300 人行道板，不是本网页默认梁。它仅用于独立核查约4.15 kN·m的荷载计算，不把该跨度和材料混入默认示例。

教材例3-5初步设计使用 `b=300, h=450, h0=385 mm`、`M=300 kN·m`，模块能重现约239.05 kN·m单筋边界、约535 mm²新增上筋和3095 mm²总下筋。模块保留全精度，不按教材中间舍入值逐步计算；教材第77页复核分母的13.3与前后13.8不一致，第83页例3-6二次方程系数与 `2h0` 不一致，第85页例3-7题干高度与后续计算高度也不一致，这些不一致不作为代码公式来源。
