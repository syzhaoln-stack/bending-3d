# 变宽截面的同一套平衡关系

`variable-section.js` 把矩形和 T 形梁中的面积相加，推广为随高度变化的净宽度积分。这是几何与静力平衡的教学扩展，不是把 T 梁规范公式未经校核直接应用为所有异形截面的工程设计方法。

坐标 `y` 从截面顶面向下，截面高度为 `h`。给定等效均匀压应力 `fc`，压块深度为 `x`，用实际净宽度 `b(y)` 计算：

\[
A_c(x)=\int_0^x b(y)\,dy,\qquad
Q_c(x)=\int_0^x y\,b(y)\,dy,
\]

\[
C_c=f_cA_c=\sigma_sA_s,\qquad y_C=Q_c/A_c,\qquad
M=f_c\bigl[h_0A_c-Q_c\bigr].
\]

内部使用 N、mm、MPa，输出弯矩乘 `10^-6` 转成 kN·m。适筋时取 `σs=fy`，保持 `h0` 和材料一致时，输入 `As` 就确定一个压力合力，再由压区面积反求 `x`；超筋趋势中则按应变协调同时求 `σs` 与 `x`。两者都沿用 `σsAs=Cc`、`z=h0−yC`、`M=Ccz` 这套平衡关系。目标弯矩反算在教学设计界限内利用单调关系进行二分求解，不要求学生对每种截面重新手工整理方程。

## 四种几何

默认主尺寸为 `bf=650, h=500, h0=460 mm`，基准腹板宽 `b=250 mm`。材料 `fc=13.8, fy=330 MPa`。

| 形状 | 净宽度与积分方式 |
|---|---|
| T 形 `tee` | 顶部100 mm厚翼板宽650，以下腹板宽250；按两个矩形精确积分 |
| 箱形 `box` | 外宽650，左右壁各75，顶底板各100；外矩形减去500×300的内孔，并按压区截断 |
| 菱形 `diamond` | 顶底尖、半高中宽650；宽度分段线性，面积和一次矩用多项式精确积分 |
| 三圆孔 `hollow` | 外宽650，三个半径70的圆孔；圆心距左135/325/515、距顶250；外矩形减圆缺精确原函数 |

圆孔在高度 `y` 处减少的净宽度是 `2 sqrt(r²-(y-cy)²)`。各孔分别积分，避免把穿孔区域误算为固定腹板宽。圆缺面积采用：

\[
A_{\mathrm{hole}}(x)=u\sqrt{r^2-u^2}+r^2\left[\arcsin(u/r)+\pi/2\right],
\]

其中 `u=clamp(x-cy,-r,r)`。其一次矩为 `cy A_hole - (2/3)(r²-u²)^(3/2)`，因此对完整孔和部分切孔都连续适用。

可选覆盖 `bf/h` 时，箱壁厚按宽度比例、顶底板厚按高度比例缩放；圆孔横向中心按宽度比例、竖向中心随半高，圆孔半径按宽和高两比例中较小者缩放，保持圆形。也可明确覆盖 `wall/top/bottom/radius/centers`。这些几何数据通过 `geometrySpec` 同时提供给三维场景。

## 两个必须区分的边界

模块统一用 `xb=0.53 h0=243.8 mm` 截断，便于比较同一控制深度下的几何与力矩。它对箱形、菱形、圆孔截面只是**共同教学截断条件**，不能据此断言其真实平截面应变、等效压块参数、延性和规范设计条件都已验证。

`limits.Amin=230 mm²` 只是统一的配筋图示起点，方便滑块和曲线可读。对于任意异形截面，模块没有声称已经验证其规范最小配筋率。结果始终带 `codeMinimumChecked=false`，`limits.minimumIsCodeCheck=false`。`valid=true` 只表示当前几何积分及所设教学截断范围可用。

原 `section(As)` 接口超过界限后返回固定的设计参考，`over=true, valid=false`。网页用它绘制设计采用的实线：界限以内上升，之后按 `x=xb` 的上限水平延长；设计抗力读数、复核与反算使用实线取值。网页另将 `compression(x)` 几何积分接入 `RCSectionResponse.solve`，使用应变协调确定钢筋应力，三维压区及 x 读数继续加深，模型抗力沿棕色虚线继续增长。实线水平段是设计取值，并非物理承载力平台；虚线也不构成推荐超筋设计的依据。任意异形截面的这段延伸仍是教学假定，不是完成规范设计的结论。

## 默认数值

| 形状 | 截断处 As（mm²） | 截断处 M（kN·m） |
|---|---:|---:|
| T 形 | 4221.54545 | 510.699291 |
| 箱形 | 3620.20000 | 453.527575 |
| 菱形 | 3231.28974 | 317.196326 |
| 三圆孔板 | 5770.06793 | 670.650185 |

这些比较未保持用料面积相同，因此不能直接解读为材料效率排名。实际截面选择还要同时比较自重、布筋、抗剪、刚度、施工等因素。

默认圆孔顶面在 `y=180 mm`，对应 `As=4892.72727 mm²`、`M=597.402 kN·m`。在配筋较少时，压区还没有到孔洞高度，压区仍是完整矩形；用 `As≈5200 mm²` 可展示圆孔进入压区后的净宽变化。菱形在 `h0=460 mm` 钢筋位置的宽度仅104 mm，其钢筋图只表示合力位置，不是可直接施工的配筋布置。

“受拉区不参与”仅指这里忽略受拉混凝土的正截面抗拉贡献。在固定 `h0`、配筋和上部压区时，仅改变压区以下的几何不会改变该抗弯积分，但会改变自重、受剪与锚固条件等。不能据此任意切断腹板或删除包裹钢筋的混凝土。

## 接口

```js
const box = VariableRC.create('box');
const s = box.section(3000);       // As, mm²
const answer = box.design(400);    // M, kN·m
const localWidth = box.widthAt(200);
```

浏览器全局 `window.VariableRC`；Node 使用 `require('./variable-section.js')`。实例提供：

- `defaults`：参数；`geometrySpec`：与三维场景共享的尺寸。
- `limits`：`Amin/xb/As/M`，T 梁另有 `transitionAs/transitionM/transitionX`；其余形状这三个单一过渡值为 `null`。
- `limits.events`：各几何高度事件及其 `x/As/M/withinLimit/name`，可用于标注箱孔、圆孔和翼板边界。
- `section(As)`：返回 `mode='tee'`、`sectionKind`、几何、`x/yC`、钢筋面积、力、弯矩和是否超过教学设计界限的状态；网页保留此结果作为设计参考。
- `design(M)`：返回 `ok/AsNeeded` 和对应正算结果。高于截断弯矩时返回 `ok=false, AsNeeded=null`。低于图示起点时采用图示起点，并返回 `adoptedDisplayMinimum=true`。
- `widthAt(y)`：实际净宽度，截面外为0。
- `compression(x)`：给定深度的压块积分，返回area、C、yC和M，可接入应变协调求解器。
- `profile`：外边界多边形及矩形/圆形孔洞，坐标从左上角起算。

## 验证

运行 `node verify-variable-section.cjs`。12项测试覆盖四形精确积分与独立宽度分条积分的对照、全截面面积与重心、T 梁与原模块一致、正反算、孔洞进入压区、菱形压区重心、独立改变受拉区域、几何比例缩放以及输入校验。

独立数值积分的最大压区面积差约 `6.915×10^-5 mm²`，最大弯矩差约 `2.661×10^-7 kN·m`。还验证了仅改变箱形底板厚度（仍完全在压区以下）会改变全截面面积而不改变本模型的抗弯积分；完全处于压区以下的圆孔也不改变压区积分。
