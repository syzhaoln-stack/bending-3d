# 四个例题看抗弯

双击 **../beam-extension-3d.html**，可在支持 WebGL 的现代浏览器离线使用。全部程序、三维引擎和字体回退均在单文件中，无需安装。原讲解稿及前面的独立网页保留。

## 一条课堂主线

| 例题 | 学生操作 | 看见的结论 |
|---|---|---|
| 1 单筋设计（教材例 3-1） | 调整下部配筋，或“按目标求配筋” | 115 kN·m 对应曲线交点；配筋增多，压区加深 |
| 2 超筋复核（教材例 3-4） | 查看 5Φ20，再拖到适筋界限 | 上下两排都是受拉筋；h0=313 mm；按上限复核约105.33 kN·m，小于要求120 kN·m |
| 3 双筋设计（教材例 3-5） | 先分开看紫色钢筋对，再点“插入梁中”；移动上部钢筋 | 原单筋部分提供界限抗力 Mb；新增钢筋对提供 ΔM=fsd·ΔA·zs，分别显示两项数值及总和；间距减小，新增贡献变小 |
| 4 T 形与变宽截面（第 3.6 节的拓展） | 先与等宽矩形并排对照，再继续加筋进入腹板 | 压区在翼缘内时，等宽矩形抗弯相同但自重更大；进入腹板后，同加300 mm²所需的压区增量由约11 mm变为29 mm |

三维模型可拖动、触控、键盘方向键旋转，F 键正视，Home 键复位，加减键缩放。曲线可点击定位配筋量。手机上先显示配筋控制，再显示模型和曲线。“黑白显示”支持课堂打印场景。

双筋页默认展示推导，可切换“查看配筋曲线”。“分开看钢筋对 / 插入梁中”移动同一组钢筋，镜头保持固定；插合过程约0.9秒，可反向或中断。键盘操作及系统的“减少动态效果”设置使用即时切换。拆分是**内力的计算分解**，实际钢筋与混凝土仍共同变形。

推导先保留原单筋基础部分，再增加一对上压、下拉钢筋。同种、同等设计应力时，上下新增面积同为 ΔA；钢筋对的力臂为 zs=h0−a′s，新增弯矩为 ΔM=fsd·ΔA·zs。基础抗力 Mb、钢筋对抗力 ΔM 和总抗力 M=Mb+ΔM 分别显示。例3-5初始状态是约239.05+60.95=300.00 kN·m。

## 全部例题共用的三个式子

主公式区保持相同顺序与符号：

1. 压力等于拉力：fcd Ac = fsd As。
2. 由混凝土压力求弯矩：M = fcd Ac z。
3. 由钢筋拉力求弯矩：M = fsd As z。

后两式是**同一抗弯能力的两种算法**，不相加。Ac 是等效受压区面积，z=ys−yc 是受拉钢筋重心与混凝土压力重心的距离；各深度从截面顶面量起。不同截面只改变 Ac、yc 的几何计算，钢筋排布改变时则重新计算 ys=Σ(As,i·yi)/ΣAs,i。主区只给对应的简短几何说明，T形分块与变宽截面的积分详式保留在展开内容中。

超筋时，主公式仍用于**设计实线**：取适筋界限的 Ac、As,b 和 z，而不是将当前超筋总面积直接乘 fsd。三维压区及虚线使用当前配筋的应变协调模型，其 σs 说明单独放在展开内容中。双筋时，主三式仅描述**原单筋基础部分**，其中 As 对应基础下筋 As,1=As,b；新增钢筋对在右侧单独计算 ΔM，下部总面积为 As,总=As,1+ΔA。

## T 形与等宽矩形的并排对照

进入第4页，默认显示“① 与等宽矩形对照”。两根梁具有相同材料、As、h0，以及相同钢筋位置；矩形宽度取T形有效翼宽650 mm。拖动任一模型可同步旋转，正视、三维及受力开关也同步作用于两图。淡琥珀色、虚线标出矩形多出的下部混凝土。

当等效压区 x≤h′f 时，两者的压区面积都是 b′f·x，压力重心都是 x/2，因此正截面抗弯公式完全相同。默认As=2200 mm²，两者x=80.936 mm，抗弯均为304.580 kN·m。比较滑块限定在598～2718.182 mm²：同时满足两者的模型最小配筋要求，并且不超过翼缘底界限。

本例T形总面积165000 mm²，宽矩形325000 mm²；相同梁长、相同混凝土容重时，T形的**混凝土自重约为矩形的51%**。这里仅比较混凝土，未将相同钢筋的重量加到两根柱条中；示意几何的实际外宽取为有效翼宽。多出的下部区域不进入本等效压块模型的抗弯抵抗，但会增加重量。x并非真实中性轴深度，所以图中没有将压块之外的全部区域一概称为真实受拉区。

点击“继续加筋，看看压区进入腹板之后”，回到原抗弯曲线和x–As图，原双筋、其他变宽截面等内容保持可用。此后不再沿用两梁压区和承载力相同的结论。

## 两个关键表述

1. **实线用于设计，虚线展示超筋趋势。**适筋段的设计实线随配筋增长，到适筋界限后，按该上限水平延长。超筋后，棕色虚线按应变协调模型继续上升；三维受压区及其 x 读数跟随这个模型继续加深，固定的 x_b 虚线标出设计界限。设计抗力读数及目标复核使用实线，水平实线不是物理承载力停止增长。主区统一展示 fcd Ac=fsd As 及同一力臂下的两种弯矩算法；虚线模型所需的 σs 关系单独解释，避免混用设计面积与当前总面积。程序按目标反求适筋设计时仍遵守教材界限，不将超筋作为推荐设计。
2. **双筋中相等的是新增上下钢筋面积。**本例受拉、受压钢筋设计强度相同，新增面积相等；下部总面积还包含原有受拉钢筋。固定 x=xb 是这条教材设计路线，不能推广成任何双筋梁的普遍状态。

## 同一套积分

从受压顶边向下取 y；b(y) 为该层参与受压的混凝土净宽度。有孔洞时先扣除孔洞宽度。

- 受压面积：Ac(x) = ∫[0,x] b(y) dy。
- 压力重心：yC = ∫[0,x] y b(y) dy / Ac。
- 设计力平衡：fcd Ac = fsd As。
- 重心间距：z = ys − yC，本页 ys=h0。
- 设计弯矩：M = fcd Ac z = fsd As z；等价于 fcd ∫[0,x] b(y)(h0 − y) dy。

矩形为常宽特例；T形和箱形是分段常宽；菱形或圆孔截面中的净宽可连续变化。它们仍然使用同一套定积分与平衡关系。受拉混凝土不直接参加该积分，但受拉区外形仍影响钢筋位置、自重、抗剪和构造。

T形过翼缘底处，R-As曲线的一阶斜率连续；进入腹板后斜率下降得更快，不人为画成一个尖角。新增x-As局部图的斜率则从 fsd/(fcd·b′f) 变为 fsd/(fcd·b)，本例为2.6倍。三个对照点的As分别为2418.18、2718.18、3018.18 mm²；x分别为88.963、100、128.696 mm。两张图表达不同的变化，不能将x-As折角替换到抗弯曲线上。

使用用户补充的《结构设计原理》第5版，PDF文件名“结构设计原理(第5版)_65-103.pdf”。相关位置：

- 例3-1：PDF第19页，印刷页69；本页先按假定h0=460 mm求设计面积，尚未选配具体钢筋。教材中间将x取整为79 mm，得到约826 mm²；程序保留精度，得到x=79.2989 mm、As=829.0339 mm²。
- 例3-4：PDF第22—23页，印刷页72—73；总面积采用5×π20²/4，重心距底67 mm，有效高度313 mm。
- 双筋原理与例3-5：PDF第24—27页，印刷页74—77。演示取教材设计阶段h0=385 mm和舍入后的弯矩计算值300 kN·m，基础抗力约239.05 kN·m；新增每侧535.37 mm²，下部总计3095.27 mm²。后续钢筋选配与实际重心复核不在本页展开。
- T形原理：PDF第30—32页，印刷页80—82，式(3-31)至(3-37)。第四例使用独立示意参数，未冒用例3-6/3-7有差异的几何条件。

箱形、空心板、菱形仅用于几何积分的拓展示意。它们使用共同的x=0.53h0教学设计参考线和统一配筋展示起点；超过该教学界限的部分可按同一应变协调假定继续展示趋势，并不表示各异形截面已经按规范确定了相同适筋界限或最小配筋。三维钢筋根数与排布用于表达受力分工，具体选筋、净距、箍筋、锚固、抗剪、裂缝与挠度需另行设计。

## 超筋后的设计实线与模型虚线

新增 `section-response.js` 用于三维模型和棕色虚线的连续展示，原 `mechanics.js` / `variable-section.js` 保留教材设计与反算接口，并给出设计实线。令混凝土顶部达到εcu，平截面给出εs=εcu(h0−c)/c；取σs=min(fy,Esεs)、x=βc，由σsAs=Cc(x)求解，再算M=Cc(h0−yC)。因此钢筋继续增加时，压区与模型抗力仍增长。超筋后的设计实线采用x=xb的上限值并水平延长；它表示设计取值，不是物理承载力平台。

默认矩形As从3000增至3300 mm²，x从254.841增至260.504 mm，M从292.404增至296.358 kN·m，钢筋应力从293.067降至272.345 MPa。教材设计参考仍为x_b=243.8 mm、M_b=284.379 kN·m。例3-4的教材复核参考105.332 kN·m保持不变，当前配筋的应变协调趋势值另为107.688 kN·m，不能混用。

教材ξ_b=.53与给定β=.8、εcu=.0033、Es=200000、fy=330推得的模型屈服转折ξ_y=.533333有小差别，两者分别保留，不偷偷修改参数使其重合。刚超设计界限的短区间内，钢筋仍可能屈服。曲线采用设计强度参数，只是简化截面模型，不是试验实测结果或允许采用超筋方案的依据。
