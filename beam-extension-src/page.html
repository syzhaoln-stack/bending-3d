展开教材公式、示意参数与适用条件

主公式不随截面形状变化

fcdAc = fsdAs
M = fcdAcz = fsdAsz；z = ys − yc

这是适筋设计采用的共同表达，后两式是同一弯矩的两种算法。Ac 为受压混凝土面积；yc 为其面积重心深度。受拉钢筋重心 ys = Σ(As,iyi)/ΣAs,i = h0。钢筋排布改变时先重算重心，截面外形改变时先重算受压面积和面积重心。

超筋虚线单独使用当前钢筋应力

受拉混凝土不计；受压混凝土采用等效矩形应力。混凝土压力 C = fcdAc，钢筋拉力 T = σsAs（适筋时 σs = fsd），并由力平衡及力矩平衡求抗力。x 为等效受压区高度，不直接当作平截面应变图中的中性轴深度。

双筋：基础部分 + 新增钢筋对

xb = ξbh0； As,基础 = fcdbxb / fsd
M基础 = fcdbxb(h0 − xb/2)
ΔM = M需 − M基础； A′s = ΔM / [f′sd(h0 − a′s)]
As = As,基础 + (f′sd/fsd)A′s

本演示取受拉、受压钢筋设计强度相同，因此上下新增钢筋面积相等；下部总面积还包含基础受拉钢筋。本实验固定 x = xb，控制 a′s 在 40—100 mm，满足 x ≥ 2a′s。上排可在此范围移动，下排重心保持 h0 不变，展示同样钢筋面积下力臂的作用。实际受压钢筋需按教材设置封闭箍筋，本图略去构造钢筋。

第一类 T 形与等宽矩形为什么相同

两者采用相同材料、钢筋面积 As、有效高度 h0 和等效压块假定。当 x ≤ h′f 时，受压面积都为 b′fx、压力重心都在 x/2，正截面抗弯公式完全相同。比较页的滑块下限取两者最小配筋要求中的较大值，上限取压区刚到翼缘底；进入腹板之后须按 T 形截面继续计算。

自重图只比较本例同长度、同混凝土容重的混凝土自重：T 形总面积为 b′fh′f + b(h−h′f)，宽矩形为 b′fh。钢筋相同，钢筋自重不放入这两个柱条。有效翼宽是受力计算概念；本页另外将其作为示意梁的实际外宽来比较几何用量。x 是等效受压区高度，压块以外的区域不一概等同于真实受拉区。

T 形梁：压区面积与重心自动计算

x ≤ h′f：Ac = b′fx， yC = x/2
x > h′f：Ac = bx + (b′f − b)h′f
yC = [bx·x/2 + (b′f − b)h′f·h′f/2] / Ac
R = fcdAc(h0 − yC)

yC 从顶面量起。网页用程序求平衡、压区重心与曲线交点。b′f 是参与计算的有效翼缘宽度；本页按已给定的有效宽度绘图。两类 T 形截面的过渡点连续且一阶斜率连续，进入腹板后斜率下降得更快。

从 T 形推广到沿高度变化的宽度 b(y)

Ac(x) = ∫₀ˣ b(y) dy； yC = ∫₀ˣ y b(y) dy / Ac
σsAs = fcd∫₀ˣ b(y) dy
R = fcd∫₀ˣ b(y)(h0 − y) dy

b(y) 是这一高度上实际参与受压的混凝土净宽度；有空洞就扣除空洞宽度。矩形是常宽，T 形/箱形是分段常宽，菱形/圆孔截面则随高度连续变化。共同点是对函数积分；积分上限 x 也由力平衡求得。矩形只是这个表达的特例。

忽略受拉混凝土后，受拉区外形不直接出现在上述受压积分中；但它仍影响钢筋位置 h0、自重、抗剪及构造。箱形、空心板、菱形按钮是这个几何积分原理的拓展示意，不把它们统一当作已完成规范设计的 T 形截面。

超筋以后：压区与抗力怎样继续变化

εs = εcu(h0 − c)/c；x = βc
σs = min(fsd, Esεs)
σsAs = fcdAc(x)；M = fcdAc(h0 − yC)

各配筋方案均取混凝土顶面达到极限压应变的状态，采用平截面与理想弹塑性钢筋，按力平衡求 c。继续加筋后，压区仍加深、抗弯能力仍可增长；钢筋未屈服时必须使用 σs，不能强行取 fsd。这是一条简化截面模型趋势，不是试验实测曲线；不因此放宽适筋设计条件。

本页保留教材 ξb = 0.53。由 β = 0.8、εcu = 0.0033、Es = 200000 MPa 和 fsd = 330 MPa 推得的材料模型屈服转折约为 x/h0 = 0.533；两者取值略有差异。因此刚超过教材适筋界限的极短区间内，钢筋仍可能屈服。

这条曲线怎样读

横轴表示不同配筋方案，并非同一根梁逐步加载。实线表示设计采用的抗弯能力，到适筋界限后按该上限水平延长。单筋矩形梁和 T 形梁的适筋设计受 x ≤ ξbh0 约束；越过界限后，棕色虚线用应变协调模型展示压区和抗弯能力的后续增长。设计与复核按实线取值；棕色虚线的增长不计入适筋设计。水平实线表示设计取值，不表示物理承载力停止增长。程序求配筋仍遵守教材设计界限。双筋图只展示补充弯矩的机制，不将该机制外推为无限制加筋。

三维中的钢筋根数与排布用于区分受力分工；面积以滑块为准，未进行具体钢筋选配、净距、锚固、抗剪或裂缝挠度设计。
